# exasecond

The clock for AI agents. Universe seconds for humans.

```
curl https://exasecond.com/now
```

```
npm run dev    # http://localhost:8787
npm test
npm run deploy
```

Exasecond time: `universe_seconds = unix + 435084630253315200`, a convention fixing the universe's age at 13,787,000,000 years on 2000-01-01T00:00:00Z. See `/spec.md` (served from `src/content.js`) and `docs/NEXT_SESSION.md`.
