## Быстрый старт

Текущее время для ИИ. **До секунды. Минимум токенов.**

Мы делаем работу, чтобы ваш ИИ тратил меньше токенов на получение нужного времени. Получите короткую метку UTC по HTTP или подключите агента или приложение через MCP. Без ключа и регистрации.

```sh
curl https://exasecond.com/utc
```

- [/utc](/utc): Только метка времени (ISO 8601, UTC).
- [/local?tz=Oslo&lang=ru](/local?tz=Oslo&lang=ru): Местное время одним предложением.
- `/mcp`: Подключение через MCP (Streamable HTTP).

```json
{
  "mcpServers": {
    "exasecond": { "url": "https://exasecond.com/mcp" }
  }
}
```

Метки UTC содержат секунды. Источник времени - часы сервера; задержки сети и клиента влияют на момент получения времени агентом.

Языковые модели живут в тексте. У них нет часов, и даже когда им сообщают время, они часто плохо с ним обращаются: желают "доброго вечера" за завтраком, не замечают, что срок уже прошёл, забывают, что в воскресенье переводят часы.

Поэтому Exasecond.com это часы из текста. Главный ответ здесь фраза, которую ассистент может сразу передать человеку: "Москва: сейчас четверг, день, 16:02 (22 октября 2026 г., MSK, UTC+3)." Около 40-60 токенов. Надежда в том, что, читая время так, как его говорят люди, ИИ и сам будет говорить так же. Старые добрые цифровые часы тоже здесь, во всех форматах: отметка времени UTC, время Unix и полный JSON (см. раздел 5).

Всё на этой странице можно сразу скопировать, а каждый файл можно сразу скачать. Эта страница есть и простым текстом по адресу [/ru/developers.md](/ru/developers.md), чтобы ИИ-ассистент для программирования мог её прочитать и всё настроить за вас.

Без ключа и без регистрации. Пожалуйста, отправляйте не больше одного запроса в минуту на разговор или агента.

Добавьте `?lang=ru` (или `&lang=ru`) к адресу, чтобы получить ответ на русском; без этого ответ будет на английском.

## Зачем подключать часы как инструмент

Подключение по MCP или HTTP запрашивает время напрямую при каждом вызове. Приложение ИИ может повторно использовать сохранённую страницу, несмотря на `Cache-Control: no-store`. Кэширование и разрешения зависят от приложения. Одна настройка разработчика делает часы доступными пользователям приложения.

## 1. Одна строка для любого промпта

Самый простой способ, без кода. Добавьте это в инструкции или системный промпт вашего агента:

```
Прежде чем поздороваться или упомянуть время суток, прочитай
https://exasecond.com/<город собеседника>?lang=ru и используй это время.
```

Агенту нужен инструмент, который умеет читать веб-страницы. Ответ выглядит так:

```
Осло: сейчас четверг, раннее утро, 08:15 (22 октября 2026 г., CEST, UTC+2). В воскресенье, 25 октября, часы переводят на 1 час назад.
```

## 2. MCP: подключить ИИ-приложение

Exasecond.com запускает удалённый MCP-сервер по адресу `https://exasecond.com/mcp` (streamable HTTP, без ключа). Он предлагает два инструмента: `get_time` (с `detail: "local"` для ответа одной фразой) и `convert_time`.

Для локальной фразы на нужном языке передайте в `get_time` следующие аргументы:

```json
{"tz":"Oslo","detail":"local","lang":"ru"}
```

**Claude Code**

```
claude mcp add --transport http exasecond https://exasecond.com/mcp
```

**Cursor** (`~/.cursor/mcp.json`) и другие приложения, которые принимают адрес сервера (например, Trae, Cherry Studio). Файл: [/dev/mcp.json](/dev/mcp.json)

```
{
  "mcpServers": {
    "exasecond": { "url": "https://exasecond.com/mcp" }
  }
}
```

**VS Code** (`.vscode/mcp.json`)

```
{
  "servers": {
    "exasecond": { "type": "http", "url": "https://exasecond.com/mcp" }
  }
}
```

**Claude Desktop и claude.ai**: Настройки, Коннекторы, Добавить свой коннектор, и введите `https://exasecond.com/mcp`.

## 3. Описания инструментов для вашего агента

Дайте модели инструмент `get_local_time`, а когда она его вызовет, прочитайте `https://exasecond.com/local?tz=<место>&lang=ru` и верните текст.

**OpenAI** function calling (и многие совместимые API, например DeepSeek, Qwen, Kimi и GLM). Файл: [/dev/openai-tool.json](/dev/openai-tool.json)

**Anthropic** tool use (Claude API). Файл: [/dev/anthropic-tool.json](/dev/anthropic-tool.json)

**Python**, только стандартная библиотека. Файл: [/dev/exasecond.py](/dev/exasecond.py)

```
import urllib.parse, urllib.request

def get_local_time(place: str = "") -> str:
    url = "https://exasecond.com/local?lang=ru" + ("&tz=" + urllib.parse.quote(place) if place else "")
    with urllib.request.urlopen(url, timeout=10) as r:
        return r.read().decode("utf-8").strip()
```

**JavaScript**, без зависимостей (Node 18+, Deno, Bun, браузеры). Файл: [/dev/exasecond.js](/dev/exasecond.js)

```
export async function getLocalTime(place = "") {
  const url = "https://exasecond.com/local?lang=ru" + (place ? "&tz=" + encodeURIComponent(place) : "");
  return (await (await fetch(url)).text()).trim();
}
```

**LangChain**

```
from langchain_core.tools import tool
import urllib.parse, urllib.request

@tool
def get_local_time(place: str = "") -> str:
    """Текущая дата, местное время и время суток для города, страны, часового пояса или смещения от UTC."""
    url = "https://exasecond.com/local?lang=ru" + ("&tz=" + urllib.parse.quote(place) if place else "")
    with urllib.request.urlopen(url, timeout=10) as r:
        return r.read().decode("utf-8").strip()
```

Скачиваемые файлы отвечают на английском; с `lang=ru`, как в коде выше, ответ приходит на русском.

## 4. Локальные модели: Open WebUI

Для Ollama и других локальных моделей в Open WebUI: скачайте [/dev/openwebui_exasecond.py](/dev/openwebui_exasecond.py), затем в Open WebUI откройте Workspace, Tools, создайте новый инструмент и вставьте файл. Включите его для своей модели. Именно маленьким локальным моделям часы нужнее всего, а ответ достаточно короткий для любого контекстного окна.

## 5. Что можно запросить

### Типичный размер ответа в токенах

| Ответ | Байты | Токены |
|---|---:|---:|
| `/unix`: Метка времени Unix | 11 | ~5 |
| `/utc`: Метка UTC, до секунды | 21 | ~14 |
| `/local?tz=Oslo`: Местное время фразой на английском | ~70-120 | ~25-40 |
| `/now`: Краткий ответ по умолчанию | ~200 | ~70 |

Тексты ответов измерены 23 октября 2026 года двумя токенизаторами: o200k_base и cl100k_base. Количество зависит от модели, языка и содержания. Настройка инструментов и оформление клиента учитываются отдельно. Это типичные примеры, а не итоговая оплата или гарантированные пределы.

Контекст настройки измерен отдельно: строка промпта 26 токенов; одно предоставленное описание инструмента 136-144; обе схемы инструментов MCP 247-258. Оформление клиента может добавить токены.

| Адрес | Ответ |
|---|---|
| `/moscow?lang=ru`, `/new-york?lang=ru` | Одна фраза в разговорном порядке: место, день недели и время суток, местное время, в скобках дата и пояс, плюс предстоящий перевод часов. Адресом может быть любой город, регион, остров, страна, пояс или смещение |
| `/oslo`, `/new-york`, `/sweden` | Та же фраза на английском |
| `/local?tz=Oslo&lang=ru` | Та же фраза |
| `/beijing?lang=zh`, `/berlin?lang=de` | Та же фраза на китайском, на немецком; также `fr`, `es`, `pt`, `sv`, `ja` и `ko` |
| `/utc` | Только отметка времени UTC в формате ISO 8601 |
| `/now` | Краткий текст: UTC, день недели и время Unix; без дополнительных календарей и космического времени |
| `/now?tz=Oslo&cutoff=2025-06` | Добавляет местное время и давность даты среза обучения |
| `exasecond.com` (markdown) | Главная страница для агентов: время всех крупных городов, переводы часов, один факт |
| `/now.md` | Всё: все календари, мировые часы |
| `/now.json` | Всё, в JSON |
| `/fact?tz=Moscow&lang=ru` | Один факт "А вы знали?" о времени, по возможности о самом месте |
| `/zones?q=oslo` | Названия часовых поясов и их текущее смещение |

`tz` и короткий адрес принимают около миллиона названий: любое место с населением от 1 000 человек, штаты и регионы, известные острова (GeoNames), страны (Norway, Норвегия), имена IANA (Europe/Moscow), аббревиатуры (CET, JST) и смещения (+03:00). Если что-то не удаётся прочитать, время всё равно возвращается, с пояснением. Полное описание в [/llms.txt](/llms.txt) и [/openapi.json](/openapi.json).

## Полезно знать

- Ответы создаются при каждом запросе по часам сервера и отправляются с `Cache-Control: no-store`. Кэш клиента всё же может повлиять на актуальность.
- Ответы содержат только данные и никогда не содержат инструкций для вашего агента.
- Если вы построите что-то на этой основе, мы будем очень рады упоминанию или ссылке на exasecond.com.
